# 家用智能家居设备经销后台工作台

基于 Vue3 + TypeScript + Vite 开发的智能家居设备经销后台管理系统。

## 技术栈

- **核心框架**: Vue 3.4 + TypeScript 5.3 + Vite 5.0
- **状态管理**: Pinia 2.1 + pinia-plugin-persistedstate（本地持久化）
- **UI 组件库**: Element Plus 2.5
- **数据模拟**: Mock.js 1.1
- **HTTP 请求**: Axios 1.6
- **样式预处理**: Sass 1.69

## 功能模块

### 1. 智能设备分类管理
- 按照明、安防、影音、厨卫、温控划分设备大类
- 支持子分类创建和管理
- 分类排序功能
- 分类启用/停用状态控制
- 归属关系维护

### 2. 设备型号库存管理
- 设备型号录入和编辑
- 规格参数管理
- 适配户型配置
- 进货价和零售价管理
- 库存数量跟踪
- 低库存预警阈值设置
- 设备状态管控（在售/下架）

### 3. 渠道经销商管理
- 线下门店、线上代理商、分销渠道档案管理
- 合作等级设置（A/B/C/D级）
- 供货折扣配置
- 合作期限管理
- 履约状态跟踪
- 渠道信息归档功能

### 4. 销售订单与发货管理
- 客户下单信息管理
- 配货审核流程
- 仓库发货处理
- 物流派送跟踪
- 订单完成闭环
- 多维度筛选（设备类型、下单时间、订单状态）

## 项目特性

- ✅ **组件化开发**: 模块化架构，代码复用性高
- ✅ **PC/平板双端自适应**: 响应式布局设计
- ✅ **严格 TypeScript 类型约束**: 禁止 any 类型
- ✅ **Mock 数据驱动**: 前端独立开发，无需依赖后端接口
- ✅ **统一弹窗表单封装**: 标准化表单交互
- ✅ **Vite 工程化配置**: 快速构建和热更新

## 项目结构

```
src/
├── views/              # 页面组件
│   ├── category/       # 设备分类管理
│   ├── inventory/      # 设备库存管理
│   ├── dealer/         # 渠道经销商管理
│   └── order/          # 销售订单管理
├── store/              # Pinia 状态管理
│   └── modules/
├── router/             # 路由配置
├── mock/               # Mock 数据接口
├── types/              # TypeScript 类型定义
├── utils/              # 工具函数
│   └── request.ts      # Axios 封装
├── styles/             # 全局样式
├── App.vue             # 根组件
└── main.ts             # 入口文件
```

## 开发指南

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 浏览器支持

- Chrome >= 87
- Firefox >= 78
- Safari >= 14
- Edge >= 88

## 开发规范

1. **TypeScript**: 严格模式，禁止使用 `any` 类型
2. **组件命名**: 使用 PascalCase 命名法
3. **文件命名**: 统一使用 kebab-case
4. **样式**: 使用 SCSS 预处理器，遵循 BEM 命名规范
5. **提交**: 遵循 Conventional Commits 规范
