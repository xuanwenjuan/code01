# 复古胶片相机选购平台

一个基于 Vue3 + Vite + Pinia + Element Plus 的复古胶片相机选购平台。

## 技术栈

- **Vue 3** - 组合式 API
- **Vite** - 构建工具
- **Pinia** - 状态管理
- **Element Plus** - UI 组件库
- **Vue Router** - 路由管理

## 功能特点

### 平台首页模块
- 相机型号分类展示
- 热门机型推荐
- 新品上架展示
- 胶片适配指南入口

### 相机详情模块
- 相机参数详细展示
- 成色等级说明
- 配件套餐选择
- 商品详情、套餐详情、购买须知标签页

### 个人中心模块
- 账号登录/注册
- 个人信息管理
- 我的订单查询
- 收藏相机管理

### 商家权限
- 商品管理（发布、编辑、删除）
- 订单管理（查看、发货）

## 项目结构

```
src/
├── components/        # 公共组件
│   ├── AppHeader.vue       # 顶部导航
│   ├── AppFooter.vue       # 底部信息
│   ├── CameraCard.vue      # 相机卡片
│   ├── LoadingSpinner.vue  # 加载状态
│   └── EmptyState.vue      # 空数据状态
├── mock/              # 模拟数据
│   └── data.js             # 所有模拟数据
├── router/            # 路由配置
│   └── index.js
├── stores/            # Pinia 状态管理
│   ├── user.js             # 用户相关
│   └── camera.js           # 相机相关
├── styles/            # 全局样式
│   └── global.scss
├── views/             # 页面视图
│   ├── Home.vue            # 首页
│   ├── Cameras.vue         # 相机列表
│   ├── CameraDetail.vue    # 相机详情
│   ├── FilmGuide.vue       # 胶片指南
│   ├── Login.vue           # 登录
│   ├── Register.vue        # 注册
│   ├── Profile.vue         # 个人中心
│   ├── Orders.vue          # 我的订单
│   ├── Favorites.vue       # 我的收藏
│   └── Merchant.vue        # 商家中心
├── App.vue            # 根组件
└── main.js            # 入口文件
```

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 表单校验规则

- **用户名**：3-20位，字母、数字、下划线
- **密码**：至少6位，包含字母和数字
- **邮箱**：标准邮箱格式
- **手机号**：11位中国大陆手机号
- **商品描述**：至少10个字符

## 成色等级说明

- **全新**：几乎全新，无使用痕迹
- **95新**：几乎无使用痕迹，功能完好
- **9成新**：轻微使用痕迹，功能完好
- **8成新**：有使用痕迹，功能正常

## 订单状态

- **待付款**：订单创建，等待支付
- **已付款**：支付成功，等待发货
- **已发货**：商家已发货，等待收货
- **已完成**：交易完成
- **已取消**：订单已取消
