# 新能源汽车电机转子加工管控系统 - 业务流程说明

## 一、系统概述

本系统为新能源汽车电机转子生产提供全流程管控，覆盖产品分类、原料仓储、生产工单、成本核算等核心业务模块，支持多岗位权限协作，实现从原料到成品的全链路追溯。

## 二、岗位权限说明

| 角色 | 职责说明 | 主要操作权限 |
|------|---------|------------|
| **ADMIN - 系统管理员** | 系统整体运维，用户管理 | 全部功能权限 |
| **PURCHASE - 采购专员** | 原料采购、分类管理 | 产品分类CRUD、原料入库、库存查询、预警处理 |
| **PRODUCTION - 生产工艺员** | 生产执行、工序操作 | 创建工单、领料/退料、完成工序 |
| **GROUP_LEADER - 产线组长** | 生产调度、工单管理 | 备料确认、工单启动、暂停/恢复工单 |
| **QUALITY - 质检员** | 质量检验、不良品管理 | 永磁体有效期检查、报废原料登记 |
| **FINANCE - 财务** | 成本核算、报表生成 | 成本计算、报表查询、对账溯源 |

## 三、全流程业务运转

### 3.1 基础数据准备阶段

**1. 产品分类配置**
```
操作人：采购专员/管理员
流程：
  1. 新增产品分类（永磁同步电机转子、异步电机转子等）
  2. 设置分类编码、优先级、排序
  3. 支持无限级树形结构
  4. 老旧型号可下线停用
```

**2. 原料基础库建立**
```
操作人：采购专员
流程：
  1. 登记原料信息（硅钢片、永磁体、转轴坯料、绝缘涂层辅料等）
  2. 设置原料类型、单位、单价
  3. 供应商信息维护
  4. 永磁体需设置低温仓储有效期提醒
```

### 3.2 采购入库阶段

**原料入库流程**
```
操作人：采购专员
流程：
  1. 新增原料入库单
  2. 系统自动生成批次编码
  3. 更新库存数量
  4. 系统自动判断库存状态：
     - 库存充足：正常状态
     - 库存预警：低于安全阈值触发提醒
     - 停止采购：库存为0或超储
  5. 生成入库操作日志
```

### 3.3 生产工单阶段

**工单创建 → 备料 → 投产流程**
```
1. 创建工单
   操作人：生产工艺员/产线组长
   - 选择产品类型、填写生产数量
   - 设置计划开始/结束时间
   - 系统自动生成工单号

2. 备料确认
   操作人：产线组长
   - 工单状态：待投产 → 备料中
   - 确认原料库存充足
   - 库存不足触发预警提醒

3. 领料出库
   操作人：生产工艺员/产线组长
   - 选择工单和所需原料
   - 填写领料数量
   - 系统扣减库存，记录用料明细
   - 关联工单与原料消耗

4. 工单投产
   操作人：产线组长
   - 工单状态：备料中 → 生产中
   - 记录实际开始时间
   - 启动第一道工序
```

### 3.4 生产执行阶段

**7道工序自动流转**
```
工序顺序：
  1. 硅钢片叠压成型
  2. 转轴压装
  3. 绕组嵌线
  4. 动平衡校正
  5. 绝缘检测
  6. 表面喷涂
  7. 成品入库

工序执行流程：
  1. 当前工序状态：待执行 → 进行中
  2. 操作人员完成工序
  3. 填写合格数量、不良品数量
  4. 系统自动将当前工序标记为已完成
  5. 下一道工序自动启动（状态变为进行中）
  6. 最后一道工序完成后，工单自动标记为已完成
  7. 记录每道工序的操作人员、开始/结束时间
```

**异常处理 - 工单暂停/恢复**
```
暂停工单：
  操作人：产线组长/管理员
  - 生产中工单可暂停
  - 记录暂停原因（可选）
  - 当前工序同步暂停

恢复工单：
  操作人：产线组长/管理员
  - 恢复到暂停前状态
  - 继续工序执行
```

### 3.5 质量管理阶段

**不良品处理**
```
操作人：质检员/产线组长
流程：
  1. 工序完成时登记不良品数量
  2. 报废原料登记
  3. 系统记录报废成本
  4. 不良品数量参与成本核算
```

**永磁体有效期监控**
```
操作人：质检员/采购专员
流程：
  1. 系统自动监控永磁体有效期
  2. 到期前30天触发预警
  3. 查询即将过期的永磁体批次
  4. 优先使用临近过期原料
```

### 3.6 成本核算阶段

**成本自动核算流程**
```
操作人：财务
触发时机：工单完成后

核算项：
  1. 原料成本（从工单用料明细获取）
     - 硅钢片成本
     - 永磁体成本
     - 转轴坯料成本
     - 绝缘涂层成本
     - 其他材料成本

  2. 生产费用
     - 设备能耗（按产量计算）
     - 人工成本（按产量计算）
     - 能源消耗

  3. 损失成本
     - 报废原料成本
     - 不良品损失

  4. 成本汇总
     - 总成本 = 原料成本 + 生产费用 + 损失成本
     - 单位成本 = 总成本 / 生产数量

输出：
  - 生成成本核算单
  - 支持按时间范围生成报表
  - 用料明细与财务对账溯源
```

### 3.7 库存管理补充

**退料流程**
```
操作人：生产工艺员/产线组长
流程：
  1. 选择工单和退回原料
  2. 填写退料数量
  3. 系统增加库存
  4. 记录用料明细（负数表示退料）
```

**库存预警处理**
```
操作人：采购专员
流程：
  1. 查询库存预警原料列表
  2. 发起采购申请
  3. 采购入库后解除预警
```

## 四、工单状态说明

| 状态码 | 状态名称 | 说明 | 可执行操作 |
|--------|---------|------|-----------|
| 0 | 待投产 | 工单已创建，未开始备料 | 备料、删除 |
| 1 | 备料中 | 正在进行原料准备 | 领料、启动生产、暂停 |
| 2 | 生产中 | 工单正在生产 | 完成工序、暂停 |
| 3 | 已完成 | 工单全部工序完成 | 成本核算、查询 |
| 4 | 已暂停 | 工单暂停生产 | 恢复、查询 |

## 五、原料状态说明

| 状态码 | 状态名称 | 说明 |
|--------|---------|------|
| 0 | 库存充足 | 库存量高于安全阈值 |
| 1 | 库存预警 | 库存量低于安全阈值，需采购 |
| 2 | 停止采购 | 库存为0或超储 |

## 六、用料操作类型

| 类型码 | 操作名称 | 说明 |
|--------|---------|------|
| 1 | 领料 | 从仓库领料用于生产 |
| 2 | 退料 | 将未使用原料退回仓库 |
| 3 | 报废 | 原料损坏报废 |
| 4 | 补充 | 额外补充原料 |

## 七、系统定时任务

| 任务名称 | 执行频率 | 功能说明 |
|---------|---------|---------|
| 超期工单检查 | 每日凌晨2点 | 检查计划开始时间超过1天的待投产工单，自动标记为已暂停 |
| 有效期预警检查 | 每日凌晨3点 | 检查即将过期的永磁体，推送预警通知 |

## 八、操作日志

系统自动记录所有操作日志，包括：
- 操作人、操作时间
- 模块名称、操作类型
- 请求参数、返回结果
- 执行耗时、IP地址
- 支持操作追溯与审计
