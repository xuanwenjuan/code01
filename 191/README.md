# 考古勘探器材采购平台

一个基于 Vue3 + Vite + Pinia + Element Plus 构建的专业考古器材采购平台。

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Pinia** - Vue 官方状态管理
- **Vue Router** - Vue.js 官方路由
- **Element Plus** - 基于 Vue 3 的组件库

## 项目特性

### 双权限系统
- **考古单位采购方**：浏览器材、采购下单、订单管理、收藏管理
- **勘探器材供货商**：商品管理、订单处理、数据统计

### 核心功能模块

#### 1. 平台首页模块
- 器材品类分类导航（6大分类）
- 野外勘探器材专区
- 室内修复器材专区
- 考古项目成套器材采购套餐推荐
- 平台服务特色展示

#### 2. 器材详情模块
- 器材精度参数展示
- 材质耐候性说明
- 考古场景适用范围标注
- 商品收藏功能
- 立即采购功能

#### 3. 个人中心模块
- 账号登录（双角色选择）
- 个人信息展示
- 器材采购订单跟踪（待付款/已付款/配送中/已完成）
- 常用勘探器材收藏管理
- 账户统计（订单数、收藏数、累计消费）

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

项目将在 `http://localhost:3000` 启动

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 功能说明

### 表单正则校验
- **账号**：4-20位字母、数字或下划线
- **密码**：6-20位字母、数字或下划线

### 状态管理
- 使用 Pinia 管理用户登录状态、收藏、订单等数据
- 数据持久化存储到 localStorage
- 路由守卫实现权限控制

### 响应式设计
- PC端适配（1200px宽度容器）
- 卡片式布局
- 流畅的过渡动画

## 数据说明

本项目全程使用本地模拟数据，包括：
- 6大器材分类，每类含4个子分类
- 12款专业考古器材
- 4种采购套餐
- 2个演示用户账号
- 3条示例订单数据

## 开发规范

- 遵循 Vue3 组合式 API 开发规范
- 组件拆分合理，公共组件可复用
- 加载/空数据等状态提示完善
- 表单正则校验严谨
